# Vitrio API

Backend do Vitrio — catálogo digital multi-tenant para revendedoras: cada
revendedora publica sua vitrine própria e recebe pedidos pelo WhatsApp.

Java/Spring Boot, do zero. Contexto de produto, decisões de escopo e
referências ainda em `../ideia.md`; próximo passo é rodar `/grill-with-docs`
neste repositório para consolidar isso em `CONTEXT.md`/ADRs antes de virar spec.

Frontend em repositório separado: `vitrio-web`.
